## Why This Exists

Generative AI is evolving at breakneck speed. New tools, agents, coding assistants, image generators, and multimodal systems appear every week. Navigating this landscape can be overwhelming, especially for students, engineers transitioning into AI, or enthusiasts who want practical, no-nonsense starting points.

These guides distill key platforms and workflows into accessible formats. Whether you are preparing for an AI course, building side projects, or simply want to understand what Claude, Grok, Gemini, Cursor, Replit, and the rest can actually do in 2026, this collection is for you.

## What's Inside

- **18 practical PDF guides** covering major AI tools, coding agents, image/video platforms, and ecosystems.
- Focus on *hands-on foundations*: prompting, vibe coding, agent workflows, and tool-specific best practices.
- Designed to be readable, shareable, and useful for self-study or classroom support.
- Fully open source — fork it, improve it, translate it, or build upon it.

All PDFs are hosted directly in this repository and are verified to be readable (non-encrypted, multi-page documents). Click any link below to view or download.

## Suggested Learning Path

1. **Foundations & Ecosystems** — Start with OpenAI Ecosystem, Gemini Ecosystem, Meta AI Ecosystem, and Claude guides to understand the major platforms.
2. **Conversational & Agent AI** — Move to Grok Bot, SuperGrok, Hermes Agent, and related agent frameworks.
3. **Coding & Building** — Dive into Cursor, Codex, Claude Code, Vibe Coding with Replit, Lovable, and Grok Build.
4. **Creative & Specialized Tools** — Explore OpenArt, Higgsfield, Julius AI, Rosebud, Base44, and others for domain-specific workflows.
5. **Practice** — Apply concepts by building small projects, prompting experiments, or contributing improvements back to this repo.

## How to Use These Resources

- **Self-study:** Download the PDFs that match your current interest and work through them sequentially.
- **Classroom / Workshop:** Use as supplementary reading for GenAI courses or hackathons (e.g., IIT Ropar-style events).
- **Team onboarding:** Share specific guides with engineers adopting new AI coding tools.
- **Remix:** Extract key ideas, create summaries, notebooks, or translated versions and submit a PR.
